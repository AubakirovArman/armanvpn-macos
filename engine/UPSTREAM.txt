Local modifications are provided in armanvpn.patch:
- Use a separate armanvpn.sock socket and daemon lock.
- Expose bounded, timestamped connection reason codes through authorized local IPC.
- Use the user-approved leaf certificate as the exclusive TLS trust anchor.
- Allow the gateway's external address to differ from the certificate's internal address.
- Disable HTTP redirects and verify the SSL tunnel's peer certificate before sending tunnel data.

Build: bash scripts/build-engine.sh
This script fetches the exact upstream source, applies the supplied patch and builds the engine.
The Swift application communicates with this separate executable through a local Unix socket.
